# Lapka Wellum 36 — ZMK keymap

Прошивка для 36-клавишной сплит-клавиатуры Lapka (Wellum 36) на базе ZMK.

Раскладка ориентирована на работу в консоли, терминальных мультиплексорах (zellij/tmux), IDE и с `kubectl`/`docker`.

---

## Базовый слой (Default)

```
Q   W   E   R   T               Y   U   I   O   P
A   S   D   F   G               H   J   K   L   ;
Z   X   C   V   B               N   M   ,   .   /
    [Ctrl/Caps] [Shift] [Nav]  [Sym] [Space] [Alt]
```

Буквы — стандартная QWERTY. Цифр на базе нет, они вынесены на numpad в `Sym`-слое.

### Home-row mods

Средний ряд работает как модификаторы при удержании:

| Клавиша | Удержание |
|---|---|
| `A` | `Ctrl` |
| `S` | `Gui` (Win/Super) |
| `D` | `Alt` |
| `F` | `Shift` |
| `J` | `Shift` |
| `K` | `Alt` |
| `L` | `Gui` |
| `;` | `Ctrl` |

### Нижний ряд больших пальцев

| Клавиша | Функция |
|---|---|
| `Caps` (удержание) | `Ctrl` |
| `Caps` (клик) | `Caps Lock` |
| `Shift` | `Left Shift` |
| `Nav` | слой навигации (`mo 1`) |
| `Sym` | слой символов/цифр (`mo 2`) |
| `Space` | `Space` |
| `Alt` | `Right Alt` |

---

## Комбо

Комбо активны на базовом слое и на `Sym`-слоe. Нажатие двух клавиш одновременно даёт скобку или кавычку. Направление нажатия определяет открывающий/закрывающий символ.

| Комбо | Результат |
|---|---|
| `Q + W` | `[` |
| `W + Q` | `]` |
| `F + G` | `{` |
| `G + F` | `}` |
| `K + L` | `(` |
| `L + K` | `)` |
| `L + ;` | `'` |
| `; + L` | `"` |

### Остальные символы через Shift

| Символ | Как набрать |
|---|---|
| `<` | `Shift + ,` (на базе) |
| `>` | `Shift + .` (на базе) |
| `?` | `Shift + /` (на базе) |
| `:` | `Sym`-слой или `Shift + ;` |

## Слой символов и цифр (Sym)

Активация: удерживать `Sym` правым большим пальцем.

```
!   @   #   $   %        `   7   8   9   :
+   =   _   -   ^        "   4   5   6   0
*   &   |   \   ~        '   1   2   3   .
```

Правая половина — numpad, удобен для IP-адресов, портов и имён вроде `pod-123`.

---

## Слой навигации (Nav)

Активация: удерживать `Nav` левым большим пальцем.

Скелет взят из оригинальной раскладки Wellum, но убраны все шорткаты (swapper, tabber и т.п.).

```
-     -     -     -     Esc        Esc   Home  End   Bksp  Del
Ctrl  Shift Alt   Gui   Enter      Enter Left  Down  Up    Right
-     -     -     -     Tab        Tab   PgUp  PgDn  -     -
```

- **Правая половина** — стрелки, Home/End, PgUp/PgDn, Backspace, Del.
- **Левая половина** — дублируются `Esc`, `Enter`, `Tab` и модификаторы (`Ctrl`, `Shift`, `Alt`, `Gui`). Модификаторы удобны для `Ctrl + →`, `Shift + ↑` и т.п.

## Слой функций (Fun)

Активация: зажать одновременно `Nav + Sym`.

```
F1  F2  F3  F4  F5        F6  F7  F8  F9  F10
F11 F12 -   -   -         -   -   -   -   -
-   -   -   -   -         -   -   -   -   -
```

Только F-клавиши.

## Русская раскладка

ZMK отправляет **позиции клавиш**, а не сами символы. Что именно напечатается, решает текущая раскладка ОС.

- В **RU-режиме** базовые буквы печатают русские символы (`Q` → `Й`, `[` → `Х` и т.д.).
- В **RU-режиме** комбо и `Sym`-слой будут давать **русские буквы**, а не скобки/символы.
- Поэтому для кода, терминала и IDE переключай ОС в **US**. Для русского текста — в **RU**.

Прошивка не отслеживает язык. Если переключаешься часто, удобнее повесить смену языка ОС на отдельное комбо (например, `F + J`).
